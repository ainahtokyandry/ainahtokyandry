## Projects

**[MacBar](https://github.com/ainahtokyandry/mac-setup)**: one macOS menu bar item that holds
several small tools, each one kept in its own repository.

| Section | What it does |
| --- | --- |
| [storage-bar](https://github.com/ainahtokyandry/storage-bar) | Free space on the startup disk |
| [claude-usage](https://github.com/ainahtokyandry/claude-usage) | All three Claude usage limits, without opening a session |
| [meetings-bar](https://github.com/ainahtokyandry/meetings-bar) | Today's meetings, one click to join, a reminder 30 minutes before |
| [job-search](https://github.com/ainahtokyandry/job-search) | Searches job boards on a schedule, keeps the openings you qualify for, and shows the next run |
